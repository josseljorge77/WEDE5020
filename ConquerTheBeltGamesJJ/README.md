Project Overview
Conquer The Belt Games is a fictional store created for the WEDE5020 PoE.

The website aims to showcase products related to the FGC (Fighting Games Community), including games, accessories, and informational content.

The project was developed following all the guidelines of the official document, including:

Minimum structure of 5 pages
Visual sitemap
Content search
Organized HTML, CSS, and JS
Complete README with all mandatory sections

-------------------------------------------------------------------------------------------------------------------

Organization Overview

**Name:** Conquer The Belt Games
**Mission:** Make access to digital entertainment easier, faster and more affordable.
**Vision:** To be recognized as the main fighting game themed store in the region.
**Target audience:** Casual, competitive gamers, parents and fighting game fans.

-------------------------------------------------------------------------------------------------------------------

Website Goals and Objectives

The objective of the website is to offer a functional, modern and intuitive platform that facilitates navigation, increases user flow and establishes a professional digital presence.

Increase user flow
Facilitate the search for games by categories
Establish professional digital presence

KPIs:
Número de visitas mensais

Current Website Analysis

The store currently does not have a website, which limits its reach, reduces competitiveness and makes it difficult to publicize launches and promotions.
The new website solves this by offering an organized catalog, intuitive navigation and informative pages.
